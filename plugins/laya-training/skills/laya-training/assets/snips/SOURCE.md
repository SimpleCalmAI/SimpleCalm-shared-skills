# SNIPS practice dataset

The files in this folder are a converted copy of the SNIPS natural language understanding benchmark (2017 custom intent engines), published by Snips. The Snips team joined Sonos in 2019, and Sonos now manages the dataset.

- **Original source:** <https://github.com/sonos/nlu-benchmark/tree/b86ac7f1577868c42158d0dec77db50956046696/2017-06-custom-intent-engines>
- **Licence:** CC0 1.0 Universal, as stated in the repository's [LICENSE](https://github.com/sonos/nlu-benchmark/blob/b86ac7f1577868c42158d0dec77db50956046696/LICENSE). CC0 places the work in the public domain as far as the law allows.
- **How it was written:** the publisher states that the requests were collected by crowdsourcing. They were written by people, not generated by an AI model.
- **Retrieved:** 28 October 2026, at commit `b86ac7f1577868c42158d0dec77db50956046696`.

## What was changed

`convert_snips.py` made `snips_train.csv` and `snips_test.csv`. Each row has the request `text` and its `intent`. The files are UTF-8 with a byte-order mark, so Excel displays accented words correctly. The slot annotations in the original files are not used.

- Training rows come from `train_<Intent>_full.json` (13,784 requests).
- Test rows come from the publisher's separate `validate_<Intent>.json` files (700 requests, 100 per intent).
- 11 training requests that also appear in the test files were removed.
- 6 invalid bytes in the original PlayMusic file were dropped.

`scripts/build_laya_dataset.py` then made `train.jsonl`, `heldout.jsonl` and `test.jsonl` with `spec.json`. It removed repeated requests (206 in training, 5 in the test set), so the files have 12,210 training, 1,357 checking and 695 test rows. `manifest.json` records the row counts and SHA-256 fingerprints.
