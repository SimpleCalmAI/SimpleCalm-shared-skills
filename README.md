# SimpleCalm AI Shared Skills

Skills and plugins we’ve built at [SimpleCalm AI](https://simplecalm.ai), shared for you to use and adapt.

Some help with practical business tasks. Others help you experiment and understand how AI works. We hope you find them useful.

## Available skills

| Skill | What it does |
|---|---|
| [Laya training](./laya-training/) | Guides you through fine-tuning and evaluating Laya, a model for focused decisions. Includes a practice dataset and a walkthrough using Kaggle. |

We’ll add more skills as we develop them.

## Getting started

1. Choose a skill from the list above.
2. Open its folder and read the installation instructions.
3. Install it in a compatible AI assistant and follow the guide.

Each skill has its own instructions, supporting files and details of any accounts or tools you’ll need. Where a Claude plugin is available, you’ll find its installation instructions alongside the skill.

## Use them. Adapt them.

These skills are shared as they are, without support. You’re welcome to copy, change and build on them under each skill’s licence.
